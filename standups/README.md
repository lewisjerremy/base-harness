# standups/

Dated standup / planning notes — one file per day, named `YYYY-MM-DD.md`. Each
note is the next standup's input: what got done, what's in flight, what was
decided, and the ranked targets for the day.

Written by the conductor session (see `RUNBOOK.md`); read by every session at
start. Prune old notes periodically — they're a working log, not an archive.
